# KB の Excel 仕様書の取り込み

## 方針

- KB 検索を `仕様/` 配下に限定し、検索結果から `.xlsx` のみを採用する。
- `download_document` で Excel 原本を Base64 として取得し、MarkItDown で Markdown に変換する。
- 既存の要求整理・必要性判断・修正案生成は、変換後の Markdown を仕様書本文として扱う。

## 実装結果

- ローカル設定と設定例に `scope_paths = ["仕様/"]` を設定した。検索件数上限は拡張子で絞る前に適用される。
- Excel の原本サイズ・展開後サイズ・形式を検査し、変換後に文字数上限を適用する。
- 出典には KB 上の `.xlsx` パスを保持する。修正文と差分は Markdown として出力し、Excel 原本は更新しない。
- テストでは、インメモリーの FastMCP で Excel の検索・取得・変換を確認する。実環境の KB への接続は対象外。
