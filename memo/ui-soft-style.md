# やわらかい UI への調整

## 計画
- 既存の画面構成と機能を維持し、深緑と直線主体の外観を調整する。
- くすみピンク、ミント、淡いブルーを使い、読みやすさを保って親しみやすくする。
- 入力欄・操作ボタン・工程表示の角丸、控えめな影、短い表示アニメーションを整える。
- デスクトップとモバイルで表示・操作・横方向のはみ出しを確認する。

## 実装
- ローズの主色、ミントの履歴領域、淡いブルーの工程アクセントに変更。
- 入力欄と操作ボタンに角丸、控えめな影、点線の区切りを適用。
- Zen Maru Gothic Regular をローカル同梱。差分・仕様書本文の等幅表示は維持。
- フォント配布元: https://github.com/google/fonts/tree/main/ofl/zenmarugothic
- ライセンス: src/aadd/static/vendor/LICENSE.ZenMaruGothic（SIL Open Font License）。
- 英語の大文字ラベルを通常の表記へ変更。短い表示アニメーションは動きを減らす設定に対応。
- API・保存処理・画面操作の JavaScript は変更しない。

## 確認結果
- `uv run python -m pytest tests/test_api.py -q`: 8件成功。
- HTML/CSS のエディター診断: エラーなし。
- ブラウザで Zen Maru Gothic の読み込みと表示を確認。
- デスクトップ1365px、モバイル390pxで横方向のはみ出しなし。
- モバイルで入力・変更編集・修正案表示を確認。操作ボタン・文書タブの文字も枠内に収まる。
- 原文・修正文・差分は等幅表示を維持。
- 表示確認データは画面内だけで使用し、通常画面への再読込みで解除。保存データは変更しない。
